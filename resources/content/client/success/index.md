## Advisory Session Booking

### Advisory Cadence
Every Maisara Solutions client relationship includes scheduled advisory sessions:
- **Weekly (Launch Phase):** During active development and launch
- **Bi-Weekly (Stabilization):** First 90 days post-launch
- **Monthly (Ongoing):** Standard advisory engagement for managed clients
- **Quarterly (Strategic):** Strategic review sessions for holistic relationship health

### Booking Process
- Online booking through client portal
- Advisor availability calendar
- Session type selection (standard advisory, strategic review, platform planning)
- Session preparation materials and context documentation

[Book an Advisory Session](/client/success/advisory-booking)

## Request & Ticket Management

### Support Categories

**Operational Support**
- Platform access and administrative issues
- Content publishing and workflow questions
- Arabic/RTL display or formatting issues
- Analytics and dashboard questions

**Advisory Requests**
- Feature evolution discussions
- Content strategy planning
- User experience refinement
- Platform expansion or new capability evaluation

**Emergency**
- Platform-impacting incidents
- Security or data access concerns
- Time-sensitive operational issues

### Request Process
1. Submit request through client portal or designated channel
2. Acknowledge and classification within defined SLA
3. Advisory response with resolution or escalation
4. Resolution confirmation and feedback loop

[Submit a Request](/client/success/requests)
